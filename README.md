# AJ-IBS Command Center

Live operations dashboard for AJ-IBS Integrated Contractors Concept Ltd.

## Features
- Project intelligence overview
- AI blueprint parser (demo mode out of the box)
- Compliance radar (LASPPPA-style)
- Streaming bill of quantities
- MEP load intelligence

## Enable live Gemini
Set `GOOGLE_GENERATIVE_AI_API_KEY` in Vercel project environment variables.
